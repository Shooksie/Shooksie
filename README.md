### Hi, I'm Sami 👋

I build **AI agent infrastructure** and the **mobile apps that talk to hardware**.

- 🤖 **AI agents & LLM tooling** — creator of [**Animus**](https://github.com/launchapp-dev/animus-cli), an open-source autonomous agent orchestrator in Rust that runs multi-model dev teams (Claude, Gemini, GPT) from YAML workflows, with a plugin ecosystem (Rust + TypeScript SDKs, HTTP/GraphQL transports, Slack/WhatsApp/Telegram/email triggers).
- 📱 **React Native + Bluetooth Low Energy** — companion apps for hardware: reliable pairing, background reconnects on iOS/Android, firmware updates over BLE (OTA/DFU), fast data sync.
- 🧱 **Full-stack** — TypeScript, React, Node, Rust, Python, Postgres. Founder of [LaunchApp](https://www.launchapp.dev/) (React & React Native starter platform) and AetherisLabs.
- 🍽️ Built and run a production restaurant POS (kitchen display, inventory, scheduling, forecasting, Mercado Pago payments) for my own café in Mexico.

**Available for projects** — BLE app rescues, React Native + BLE companion apps, AI agent builds. Based in Mexico, working with US teams.
